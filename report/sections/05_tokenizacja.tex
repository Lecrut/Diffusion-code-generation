\section{Tokenizacja }
\label{sec:tokenizacja}

Do tokenizacji wykorzystywany jest model \texttt{Qwen/\allowbreak{}Qwen2.5-\allowbreak{}Coder-\allowbreak{}7B}. W preprocessingu na końcu kodu dopisywany jest specjalny token \texttt{[CODE\_EOS]} oraz zapewniane jest istnienie tokenów \texttt{pad} i \texttt{mask}. Instrukcje są normalizowane przez zamianę na małe litery i redukcję białych znaków, natomiast kod jest tokenizowany bez takiej normalizacji.
